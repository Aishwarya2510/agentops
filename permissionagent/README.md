# Agent Maestro Synthetic Enterprise Knowledge Base

This is a fictional, anonymized enterprise operations knowledge base for testing an AI operations agent system.

It includes:
- Finance / RevOps / Billing / Collections / Cash Application / Customer Service content
- Approval thresholds and refund logic
- Regional exceptions
- Known contradictions and outdated processes
- Missing ownership and duplicate knowledge
- Escalation paths
- Email templates
- Test cases for eval and observability

Purpose:
Use this knowledge base to test whether Agent Maestro can:
1. retrieve the right context,
2. detect gaps and contradictions,
3. route issues to the right workflow,
4. flag risk,
5. draft useful communications,
6. create improvement backlog items,
7. fail safely when knowledge is missing.

Important:
Some files intentionally contain errors, contradictions, missing details, outdated steps, and conflicting ownership. This is deliberate so you can test observability and eval.
